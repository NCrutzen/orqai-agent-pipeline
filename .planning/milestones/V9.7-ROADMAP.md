## Overview

`info@` (smeba + fire-control) actionable mail is classified on *destination* by a Stage-3 router and forwarded to the right departmental mailbox without a human. Registry-driven on the canonical 5-stage funnel, **no Stage 2** (routing needs no customer resolution), **zero `if swarm_type==='info-routing'` branches** (SWARM-02). First concrete consumer of the V10.0 ambient learning-loop.

Shipped scoped to the info@ routing win. Phase 133 (NL routing-config + verkoop→order) and Phase 134 (ambient-loop) were **deferred out of V9.7** on 2026-06-25 — see Milestone Summary.

## Phases

### Phase 130 (P0): info@ Stage-1 noise-recalibration
**Goal:** Close the ~50% latent-noise leak in the info@ "unknown" pool by registering new `classifier_rules` candidates (cold-sales/SEO, newsletters, auto-dealer spam, job applications, survey invites) through the existing Wilson-CI shadow→promote gate; noise share of the pool drops ~50%→<20%, giving the router a clean denominator. **Plans:** 5/5. (completed 2026-06-16)

### Phase 131 (P1): Destination taxonomy + Stage-3 router
**Goal:** Freeze the 6-7 destination buckets + verified mailboxes as `public.routing_destinations` (brand-aware, RLS, codegen DestinationKey); build the `info-routing-coordinator` Orq agent (Haiku-EU + 3 validated fallbacks, strict json_schema) classifying on destination; closed-list Zod gate collapsing invalid output to `unrouted`; two-layer duplicate-delivery guard; ROUTE-08 shadow match-rate harness (≥0.85, false-100% guard). No Stage 2. **Plans:** 5/5. (completed 2026-06-17)

### Phase 132 (P2): Forward side-effect + Bulk Review
**Goal:** Stage-4 Outlook-forward (idempotent, dry-run-gated, brand-aware) via a 2-call Graph helper + per-bucket release gate + D-02 forward-state idempotency; routing-category stamp-back; swarm-generic info-routing Bulk Review detail pane reusing the bulk-review primitives. **Plans:** 4/4. (completed 2026-06-18)

### Phase 132.1 (P2.5, INSERTED): Router go-live — dispatch-wiring + activation + shadow-precision gate
