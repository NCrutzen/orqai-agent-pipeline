<objective>
Build the retroactive backfill sweeper for sales-email Stage-1 noise (CLEANUP-02). It re-evaluates each ingested email's Stage-1 disposition, auto-archives the high-confidence registry-derived noise set in `verkoop@smeba.nl`, routes ambiguous matches to Bulk Review, skips loopback entirely, and is idempotent on re-run. Ships INERT against live mail in this plan: the worker writes only in `mode='canary'|'full'`, and even then only after the Wave-2 checkpoint authorizes a run — Wave 1 lands code + a `mode='report'` dry-run that writes nothing.

Purpose: Sweep the already-ingested corpus so historic noise that arrived before the live flip gets cleaned up safely, without duplicate archives and without ever auto-archiving a real sales lead.
Output: Backfill Inngest worker + two pure helpers (disposition, candidate selection w/ Graph-id resolution) + RED-first test suite.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| backfill worker → Graph (verkoop@smeba.nl) | The worker issues live archive/categorize moves against a real customer mailbox |
| backfill worker → pipeline_events / automation_runs | Worker writes ledger + predicted rows (dedup-critical) |
| corpus rows → archive target | A wrong id or wrong disposition archives the wrong message |
