## Sampling Rate

- **After every task commit:** Run `cd web && npx vitest run <touched test file>` (< 30s)
- **After every plan wave:** `cd web && npm test` + `npm run codegen && git diff --exit-code` + `npm run check:supabase`
- **Before `/gsd:verify-work`:** Full suite green **and** a LIVE shadow run reporting `status='graded'` (not `insufficient_sample`) per mailbox before any auto-flip is armed
- **Max feedback latency:** ~30 seconds (quick), minutes (full)
