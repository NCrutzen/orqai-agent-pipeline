<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Graph → backend | Externally-supplied attachment metadata + binary content (untrusted) |
| attachment bytes → unpdf/LLM | Malicious/corrupt/oversized files crossing into parsers |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-116-04 | Denial of Service | Oversized attachment exhausting memory/cost | mitigate | Cap-before-download (`maxSizeBytes` → skipped_cap), `maxVisionPages` cap on vision, `maxExtractedChars` cap on output (Task 2) |
| T-116-05 | Denial of Service | Malicious/corrupt PDF crashing the worker | mitigate | unpdf parse in try/catch → `extraction_failed` fail-soft; never propagate (Task 2, D-03) |
| T-116-06 | Tampering | reference/itemAttachment (OneDrive link, no bytes) treated as a file | mitigate | `@odata.type` type-guard in listAttachments + non-PDF/image contentType → `unsupported` status, no fetch (Tasks 1+2, A4) |
| T-116-07 | Spoofing/Tampering | direct LLM key bypassing the mandated Router | mitigate | Vision fallback goes through Orq.ai Router only; no direct LLM key; list_models-validated model id (Task 2) |
| T-116-SC | Tampering | unpdf install (slopcheck unavailable at research) | mitigate | Belt-and-suspenders blocking-human package checkpoint: npmjs verify + empty postinstall (checkpoint task) |
</threat_model>
