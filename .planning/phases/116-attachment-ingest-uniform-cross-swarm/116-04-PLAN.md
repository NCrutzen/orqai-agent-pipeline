| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-116-11 | Denial of Service | extracted text serialized into Inngest events → oversized payloads | mitigate | Text written to table; only ids/counts returned/emitted (Task 2, Pitfall 4) |
| T-116-12 | Tampering | replay-unsafe non-deterministic storage keys → duplicate objects / wrong-key updates | mitigate | Deterministic `${email_id}/${attachment_id}` keys; timestamps inside step.run; no destructured send (Task 2, Pitfall 6) |
| T-116-13 | Availability | one corrupt/oversized attachment stalling the funnel | mitigate | Per-attachment step.run + try/catch → status; Stage 2 always re-emitted (Task 2, D-03) |
