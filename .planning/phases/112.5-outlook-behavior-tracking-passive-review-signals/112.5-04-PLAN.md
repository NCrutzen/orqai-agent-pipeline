<objective>
Bedraad de pure helpers (Plan 03) + de datalaag (Plan 02) tot één durable, REGISTRY-DRIVEN Inngest delta-sync worker (SC-1 + SC-2). De worker itereert ALLE `public.swarms`-rijen met `behavior_tracking_config.enabled=true` (geen hardcoded swarm-lijst — conform `docs/agentic-pipeline/README.md`, 0 per-swarm branches), pollt per swarm cron-based (business-hours) de getrackte folders, extraheert transities, leidt review-signalen af (incl. restore=correctie via ledger-join op de swarm's swarm_type), en schrijft idempotent naar `swarm_email_transitions` + `swarm_review_signals`. Eerste run per folder = bootstrap (0 signalen, alleen token + folder-map opslaan).

**Deze fase is alleen sales-email enabled** (de Plan 02 seed). De code itereert echter generiek; een nieuwe swarm activeren = één registry-UPDATE op behavior_tracking_config, geen code-change.

Purpose: maak de passieve feedback-loop live — Outlook-gedrag wordt de de-facto sales review-surface zonder teamgedrag-wijziging, op een engine die elke swarm hergebruikt.
Output: de worker, route-registratie, een worker-level test (mock graphFetch + supabase), en een orchestrator-gedraaide eerste live delta-tick met verificatie.
