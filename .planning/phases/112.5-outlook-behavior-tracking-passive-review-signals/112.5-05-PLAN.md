## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator → Outlook category edit → delta-sync | The operator's category change is untrusted input observed via Graph delta; it must map deterministically to a verdict, never spoof another message's signal. |
| worker → public.swarm_written_categories | Read-only baseline join; the worker only SELECTs (never writes) the Phase-117-owned table. |
| baseline → swarm_review_signals | A wrong baseline→immutable_id inversion could attribute an edit to the wrong email_id. |
