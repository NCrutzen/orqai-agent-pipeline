| Boundary | Description |
|----------|-------------|
| browser (operator) → server action | operator-supplied bucket/email_id/run_id crosses here (untrusted) |
| forward-now action → forward worker (Inngest event) | an operator can force a forward bypassing the per-bucket gate |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-132-09 | Spoofing/Elevation | unauthenticated call to a routing action | mitigate | auth gate (getUser → 401) on every action, mirroring override-actions |
| T-132-10 | Tampering | forward-now forcing a forward of algemeen/unrouted/already_addressed | mitigate | forwardNow HARD-REFUSES unrouted / null-target / already_addressed before any send (OQ-3) |
| T-132-11 | Information Disclosure | re-route to an arbitrary/wrong bucket leaking mail | mitigate | rerouteBucket re-resolves via resolveRoutingDestination (registry) — an unmatched bucket→null target→not forwardable; env_id='BX' inherited |
| T-132-12 | Tampering | forward-now bypassing dedup → double-forward | mitigate | forward-now still runs through the worker's dedup + forward_state idempotency (bypasses only the per-bucket gate, not dedup) |
